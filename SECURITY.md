# Security Policy

## Supported versions

The current draft of the `+AI` specification is supported on the repository's
default branch. Earlier drafts are not separately maintained.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, exposed credentials, or security
incidents in a public issue. Report them privately using
[GitHub's private vulnerability reporting flow](https://github.com/japer-technology/ai-helped/security/advisories/new).

Include a clear description, affected files or versions, reproduction steps,
and potential impact. Maintainers will acknowledge reports, assess the issue,
and coordinate any needed disclosure or remediation.

For non-security bugs, documentation questions, and proposals, use the normal
issue tracker.
